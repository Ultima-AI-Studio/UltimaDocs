## 二、设计方向（为什么这么定）

**视觉人格：监督工作台（深色、冷静、数据优先）。**

| 决策 | 理由 |
|---|---|
| 深色主基调 | 监督仪表盘是"扫状态、看异常"的高频工具：深色底让数据与预警标识更突出（监控台惯例），碎片时间/低光环境查看不刺眼 |
| 单一强调色（蓝） | 只用一个强调色承担"主操作/选中/链接"角色；异常用红/橙独立表达，不抢强调色职责 |
| 圆角三档、"可点才圆" | 卡片/弹窗 12、按钮 8、标签角标 4；可点元素明显区别于展示元素 |
| 系统字体优先（HarmonyOS Sans） | 鸿蒙原生体验，免授权、渲染一致 |
| 无产品图片 | 卡片信息目的是"读状态"，文字+标识密度最高（UX 已定）；不引入图库素材 |

## 四、组件视觉规格（视觉状态与 UX 状态一一对应）

| 组件 | 用途 | 语义引用 | 视觉状态（对齐 UX 定义） |
|---|---|---|---|
| 产品卡 | 产品卡片集合 | §3.3 | 默认 / 按下（按压反馈）/ 加载（数据读取中）/ 禁用（数据源不可用）/ 错误（读取失败） |
| 工单条目 | 工单列表/详情 | 底 color-card-bg、边 color-line | 默认 / 展开（子层缩进）/ 加载 / 错误 |
| 按钮·同意 | 审批弹窗 | §3.3 主按钮 | 默认 / 按下 / 提交中（转圈）/ 禁用（非待审）/ 错误 |
| 按钮·打回 | 审批弹窗 | §3.3 危险按钮 | 默认 / 按下（先出确认层）/ 提交中 / 禁用 / 错误 |
| 通道筛选 | 卡片集合顶部 | 底 color-card-bg、选中 color-brand | 默认 / 选中（填充强调）/ 禁用 |
| 刷新 | 系统页 | 默认 color-brand 描边 | 默认 / 同步中（禁用+转圈）/ 错误 |
| 预警项 | 需关注清单 | 字 color-warn / color-alert | 未读（标识）/ 已读（弱化字色） |
| 采纳/忽略 | 小助手建议 | 采纳 color-ok、忽略 color-text-sub | 默认 / 提交中 / 禁用（建议未就绪）/ 错误 |
| 侧栏菜单项 | 左侧菜单 | §3.3 | 默认 / 选中（强调色+面板底）/ 禁用 |
| 悬浮球 | 审批入口 | §3.3 | 无审批（低显示度）/ 有审批（强调色+数字角标）/ 按下 |
| 审批弹窗 | 待审方案 | 底 color-overlay-bg | 默认 / 确认层（打回二次确认）/ 提交中 / 成功反馈 |

> 视觉状态数量与 UX 方案的"默认/按下/加载/禁用/错误"及各组件专有状态完全对应，不增不减。

## 五、排版栅格（多端量化）

| 端/方向 | 版心 | 分栏 | 卡片基准 | 留白 |
|---|---|---|---|---|
| 鸿蒙 Pad 横屏（2560×1600） | 侧栏 320 + 内容区 2240 | 内容区 12 栏，卡片占 3 栏（每行 4 张） | 卡片宽 ≈512、高自适应 | 内容区外边距 24；卡片间距 16；板块间距 32 |
| 鸿蒙 Pad 竖屏（1600×2560） | 顶部菜单栏 64 + 内容区 1600 | 内容区 12 栏，卡片占 4 栏（每行 3 张） | 卡片宽 ≈384 | 外边距 24；卡片间距 16；板块间距 32 |
| 其他端（第二阶段） | 冻结本方案后复用同一 tokens，按视口重算 | 12 栏基准不变 | 按视口换算 | 留白跟视口走 |

**防溢出约束**：卡片流按可用宽度自动换行排布（每行张数随宽度取整），**任何宽度下不横向溢出屏幕**；长内容（审计报告）在卡片内纵向滚动，不撑宽。

## 六、设计系统

### 6.1 视觉语言（4 条原则）

1. **数据优先**：数字用 type-data 突出；状态用标识+文字双表达（不单靠颜色）
2. **状态可视**：每张卡片一眼读出 通道/评分/偏移/阻塞/待拍板（标识齐全）
3. **单一强调**：全系统只有强调蓝承担"可点/选中"；红只给异常，不抢强调
4. **克制留白**：深色底+面板分层，板块间距 32 保证扫描节奏，不做装饰性元素

### 6.2 tokens 全集 / 组件库

见 §三 / §四（三层 tokens 表 + 组件视觉规格表，组件只引语义层）。

### 6.3 示例屏（视觉呈现描述，供 UI 落地对照）

- **产品卡片集合**：深色底 + 四板块标题行（type-display 弱化处理）+ 卡片流；每卡：左上产品名（text-title）、右上通道标签（Codex 蓝边 / DeepSeek 紫边）、中部评分数字（text-data 28）+ 偏移标识（-N 用 warning 色 / 无偏移用 ok 色）、底部状态行（阻塞用 alert 色文字、待拍板角标数字）；卡片圆角 12、面板底、1 分隔描边。
- **总览**：顶部指标条（5 个数字块，数值 text-data、标签 text-caption）+ 评分汇总（每产品一行：名 + 评分 + 偏移标识）+ 需关注清单（预警行 warning/alert 色标识）。
- **审批弹窗**：浮层底 color-overlay-bg、圆角 12、顶部标题"待审批"（text-title）、中部方案来源 + 小助手总结（text-body）+ 建议与影响分析、底部两按钮（同意=强调蓝底白字 / 打回=危险红底白字）；打回二次确认层。

## 十、冻结验收记录（用户拍板 · 2026-10-18）

**验收方式**：高保真预览 `docs/UI预览-v0.1.html`（v5.33 终版）逐屏验收，7 屏（横屏·总览 / 产品卡片集合 / 产品详情 / 文档库 / 悬浮球小助手 / 竖屏·总览 / 竖屏·产品）全部通过后用户确认"都确定了，可以进开发了"。

**用户拍板修订项（即冻结呈现规则，§六.3 过时呈现描述以此为准）**：

| 项 | 冻结规则 |
|---|---|
| 主导航 | 总览 / 产品 两项（"系统"功能移除，后续有需求再按需加回） |
| 产品卡片 | 右上通道标签删除；卡内仅：产品名 + 评分/偏移 + 当前进展版本号；状态与提示（开发中/需关注/阻塞/待拍板）进详情页，不堆卡片 |
| 产品详情·介绍 | 产品介绍文案（商业计划书式三段：定位/能力/链路），非状态信息卡 |
| 产品详情·标签组 | 介绍 / 任务队列 / 文档库 三项（审计评分删除） |
| 任务队列 | 独立屏删除，并入产品详情"任务队列"标签（统计卡 + 工单行 + 子任务就地展开） |
| 文档库 | 文档行点击就地展开完整正文，底部版本/来源/更新时间元信息；无外部"打开文档"按钮 |
| 悬浮球 | 默认位右下角 60/60；球 108vp；头盔 logo + 镜片推光同框锁死比例；无圆底、无呼吸灯（定稿参数见 §十二）；点击弹审批浮窗：背景变暗 + blur(6px)、浮窗打开时球隐藏、收起恢复（交互详见 UX 方案 v0.2 §3.6 + 预览「悬浮球小助手」tab） |
| 总览 | 标题/副标题右对齐 + 下方暗色分割线；KPI 数字滚动 + 评分条/分值联动增长动画，减速停止，仅首次打开播放 |
| 竖屏 | 导航标签左对齐；选中态平滑过渡（背景 + 底部蓝线 scaleX 展开）；左右滑动屏幕切换标签 |

## 十一、启动页视觉定稿（v1.1 追加 · 2026-10-18 用户拍板）

**设计稿**：`docs/splash_landscape.png`（横屏）/ `docs/splash_portrait.png`（竖屏），程序化生成脚本 `splash_design.py`（C 盘工作目录可重跑）；动效版 = 预览「启动页」tab（横屏 `.sdemo-in` / 竖屏 `.sdemo-in-v`，与设计稿同参数）。

### 11.1 布局参数（横 / 竖）

| 元素 | 横屏（16:10） | 竖屏（10:16） |
|---|---|---|
| 深色底 | `#0F1420` + 中央径向微光 `#1E2A3D` | 同左 |
| 头盔 logo | 宽 17%，顶部 ≈24% + 42vp（居中） | 宽 34%，顶部 ≈20% + 20vp（居中） |
| 品牌名 Ultima Console | 48vp（≈5.3% 容器宽），顶部 ≈54% + 12vp；Ultima=#E6EAF2 / Console=#3D7EFF | 24vp，顶部 44.1% |
| 副标题「极致造物，定义终局」 | 26vp，顶部 ≈65% − 38vp（贴合主标题） | 13vp，顶部 49% |
| 底栏「Ultima AI Studio」 | 12vp，顶部 92%（Ultima U / AI / Studio S 大写） | 11vp，顶部 92% |
| 星星 | 14 颗（3vp 白点 + 光晕 ≤4vp），2.4–3.4s 错相位 opacity 0.12↔0.95 循环 | 12 颗（同参数） |

### 11.2 镜片推光（横竖屏同参数）

白色光条 70% 不透明（中心 `rgba(255,255,255,.7)`、两侧 10% 渐变透明），斜扫 `skewX(-18°)`，1.5s 周期「淡入→扫过→淡出」；纵向弧度衰减（中间亮带 49.7%–50.3%、上下渐隐）；蒙版椭圆 `ellipse(31% 23% at 50.8% 51.5%)` 限幅在镜片内，`mix-blend-mode: screen`；推光定位与头盔严格同步（同 top/left/宽）。

### 11.3 时间线（横竖屏统一，总 2s）

| 时间 | 行为 |
|---|---|
| 0s | 出现**即直接显示图像**（无淡入等待） |
| 0–2s | 星星全程闪烁（循环） |
| 0–1.5s | 镜片推光：出现即开始，淡入→扫过→淡出 |
| 1.5–2s | 整体渐隐 0.5s（opacity 1→0 ease-out，品牌名/副标题/底栏/星空/头盔全部元素同步淡出）；主界面同时淡入约 0.2s 交叉过渡 |
| 2s | 主界面完全显示 |

**硬约束**：禁止瞬时硬切（无"咔嚓闪断"）；单次播放不循环、不可停留；`start_window_background` 由 `#FFFFFF` 改 `#0F1420` 消除白底闪屏。

## 十二、悬浮球视觉定稿（v1.1 追加 · 2026-10-18 用户拍板）

**视觉基准**：预览 `docs/UI预览-v0.1.html`（「悬浮球小助手」tab / 各屏右下角悬浮球）；素材 `docs/helmet.png`（2048² 透明底）。

### 12.1 结构（logo 与推光锁死比例）

悬浮球 = 头盔 logo 与镜片推光**同框锁定**：单一容器内 `<img>` 满幅（`object-fit: cover`）+ 推光层 `inset:0` 同框，椭圆蒙版与光条全部用相对 %——任何尺寸调整 logo 与推光等比联动。**禁止**拆成独立固定像素分别调。

### 12.2 参数

| 项 | 定稿值 |
|---|---|
| 球尺寸 | **108vp**（横竖屏一致；72 偏小 / 144 过大，用户拍板 108） |
| 默认位 | 右下角 right/bottom 60vp；可拖动（位移超 8px 抑制点击弹出）；旋转（横竖屏切换）回默认位 |
| 圆底 / 呼吸灯 | **无**（背景透明，不显示背景圆；取消外发光呼吸动画） |
| logo | `helmet.png` 满幅 cover，圆形裁切（border-radius 50% + overflow hidden） |
| 推光 | 与 logo 同框（inset:0）；椭圆蒙版 `ellipse(31% 23% at 50.8% 51.5%)` 限幅镜片；光条宽 60%、`skewX(-18°)`、中心白 `rgba(255,255,255,.7)` 两侧渐变透明；纵向弧度 mask `linear-gradient(to bottom,transparent 0%,#000 49.7%,#000 50.3%,transparent 100%)`；`mix-blend-mode: screen`；`sweep` 1.5s ease-in-out 循环（淡入→扫过→淡出） |
| 角标 | 红色数字角标：有审批显示，无审批隐藏；数字为待审批数 |
