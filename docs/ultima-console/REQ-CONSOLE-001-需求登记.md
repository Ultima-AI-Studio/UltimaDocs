## 需求要点（登记版）

1. 只监督不派发：APP 读监督 + 审核 + 下达指令，不直接改文档
2. 数据链路：本地（权威源）→ GitHub（桥接）主通道；**飞书灾备推迟第二阶段**（首版不做飞书授权/文档读取，N8）
3. 四板块：沟通规划中 / 开发中 / 已开发结束 / 已上线
4. 每产品可钻取：规划/介绍 → 功能与页面/UI-UX 设计 → 阶段计划 → 任务计划与工单 → 任务单元逐层展开 → 执行状态（版本/阶段）→ 工单审计报告 → 项目进度
5. 只出结果：对话沟通过程不显示，统一标准制式结果
6. 评分评估：**评分=100 基础分，按未关闭缺口严重级扣分（P0 未关闭 -10/项、P1 未关闭 -5/项、P2 未关闭 -1/项上限 -5；已处理缺口半扣：P0 -5、P1 -2.5；低于 0 记 0，结果取整）**；偏移=评分相对上次审计基线，变化 ±5 分内为无偏移，超过则标记偏移并给出纠正建议（来源=问题清单项）
7. 小助手：审核 / 总结归纳 / 给建议 / 关键节点汇报；经用户同意后反馈本地文档库或 GitHub，形成闭环
8. **偏离预警阈值（任一命中即提示）**：评分下降 ≥5 分（相对上次审计）／存在 P0 未关闭缺口／存在阻塞状态工单／工单执行中超过 7 天未冻结；均未命中则不提示
9. 鸿蒙原生 + 可旋转：横屏双栏（左导航右内容）/ 竖屏独立布局
10. 多端路线：鸿蒙（第一）→ iOS/Mac → 安卓/Windows（第二，基准版本定型后同步）；飞书灾备并入第二阶段
