文档库

UltimaConsole 是 Ultima 体系的一体化监督控制台，面向单 Owner 的 AI 产品群管理场景。它将全部产品的推进状态、阶段进度、质量评分与待办事项聚合于一块鸿蒙平板之上，Owner 打开即可纵览全局：每款产品处于哪个阶段、评分有无偏移、哪些决策等待拍板，一目了然。

产品提供三层核心能力：全局监督——总览屏聚合全部产品的状态、评分、偏移与待拍板事项；产品钻取——逐产品查看策划、设计、技术、测试、发布全链路的文档与工单队列；审批助手——悬浮球小助手即时送达待办与审批，决策不遗漏。

数据以本地为权威源、经 GitHub 桥接同步，保证监督数据的实时与可追溯。产品的北极星指标为 Owner 每周主动打开 ≥5 次，目标是成为 Ultima 体系持续运转的监督中枢。
