## 三段式任务细则（防止 AI 自行发挥）

| 段 | 要求 | 反例 |
|---|---|---|
| **文件** | 精确到文件路径（`src/xxx.h/.cpp`） | "实现网络模块" ❌ |
| **写什么** | 逐条可执行（编号 1.2.3...），引用规范章节 | "按最佳实践实现" ❌ |
| **验收** | 封闭清单（可命令验证：单测/构建/压测），全绿才过 | "代码质量好" ❌ |
| **禁止** | 明确不做什么（清单外字段/表/功能） | 缺失 ❌ |

## 验收证据要求（05 §4.5 自证 + 工程化底线）
1. 验收清单逐项结果（✅/❌ + 命令输出粘贴）
2. 改动文件清单（与"写什么"一一对应）
3. 越界声明（无=明确写"无"）
4. 单测命令 + 覆盖率
5. 构建验证（零警告 + 双构建）
6. **代码审查门**：对照审查六项（接口/线程/事务/资源/错误/性能）独立复核结论（通过/需修改），需修改=打回
7. **CI/预检**：precheck 一条命令输出（构建+单测+扫描）全绿
