## 八、沟通偏好（必须遵守）

1. 文字不要多，用 **一/二/三/四** 精简沟通
2. 界面/文档用语用规范中文管理语言：状态=未开始/进行中/阻塞/已完成/已终止；事项=待立项/待需求/待设计/待开发/待测试/待上线/已上线；问题=开发错误/需求变更/缺陷/阻塞项/待解决
3. 不口语、不拟人化、不夹英文工程词（bug→缺陷、PRD→需求方案、commit→代码提交；英文仅保留产品名专有名词）
4. 沟通期间先记录讨论点，不逐轮落盘；用户明确说"可以落盘"时再统一梳理落盘

## 九、关键规则速查（勿违反）

1. 所有新产品一律在 `H:\UltimaAI\` 下建目录，Ultima 开头，不另起路径
2. 新增内容落范式目录（docs/tasks/reports/ops/src/artifacts/sync），存量原目录不再写新内容
3. 双通道：A=豆包（带审查）、B=DeepSeek（无审查），标准统一、通道独立、审查权归用户
4. 开发只走 8 技能体系，不另起流程
5. 治理体检 U1 根目录合规每次必查
