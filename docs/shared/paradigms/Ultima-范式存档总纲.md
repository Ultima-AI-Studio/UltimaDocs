## 二、范式登记规则

- 新增范式：写完整方案 → 评审 → 批准 → 存档 `_shared\paradigms\` → 在此登记。
- 范式变更：走评审流程，旧版归档只读，新版重新登记。
- 硬约束范式（如根目录）必须可被治理体检核验。

## 三、硬约束摘要（由各范式定义）

1. **根目录**：所有开发在 `H:\UltimaAI\` 下，产品目录 Ultima 开头，不另起路径。
2. **命名**：产品名 Ultima 开头；Tuppo 字样不再作为产品名。
3. **三层数据**：本地权威 → GitHub 桥接 → 飞书备份，同一制式；GitHub 统一组织 **Ultima-AI-Studio**（私有仓）、授权走 GCM+PAT、禁硬编码 token、失效排查与新建仓库 SOP 见《UltimaAI-全局根目录范式-方案》§5.1。
4. **目录结构**：每产品 `docs/tasks/reports/ops/src/artifacts/sync` 统一骨架。
5. **Codex 调用**：显式 `-m` 指定模型（默认 gpt-6.1-sol 已失效）；派发用 `- < dispatch-*.txt` 喂文件；只归档+同步≠派发，必须真正触发 `codex exec`；WIP 执行中 ≤2；工单三段式 + DoR 五项 + 回执必报字段（详见 Codex 外部执行端调用范式）。
6. **任务路由**：产出型任务（报告/方案/审计/代码/文档等可写成封闭工单的）默认派 Codex，豆包只转工单+验收交付；交互型任务（问答/决策/偏好确认）豆包直做；对所有会话窗口（新开与旧窗口）统一生效（详见 Codex 外部执行端调用范式 §0.1）。
7. **品牌资产**：所有产品品牌引用统一从 `_shared\brand\` 取用（主标/图标/启动页/参考图），禁止各项目散存新版本；变更须登记清单并同步镜像（详见品牌资产库 README）。
8. **UI 样式**：全系产品界面字体（中/英/数字/等宽四类）、字号阶梯（72→24 唯一字号表）、深色色板（禁止自造色）、胶囊标签（圆角 4px/字重 500/角标 10px）、表单与表格样式统一按 `Ultima-UI样式范式.md` 执行，禁止自定义新字号/新颜色/改胶囊形态；**应用图标**统一深底 #0F1420 + **宇航员半身像（astronaut.png）112%、圆角=边长×22%、边框裁切躯干**、桌面/Web 同 112% 比例、禁止图标内文字（详见 UI 样式范式 §十三）。

## 四、维护

- 本总纲是范式的入口索引，不重复实现范式内容。
- 新增/调整范式时同步更新本总纲。
