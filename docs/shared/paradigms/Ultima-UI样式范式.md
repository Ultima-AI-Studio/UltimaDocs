## 一、字体（全产品锁定，禁换）

| 用途 | 字体 | 规则 |

## 三、颜色（深色主题唯一色板，禁止自造色）

| 变量 | 色值 | 用途 |
|---|---|---|
| `--bg` | #0F1420 | 页面背景 |
| `--surface` | #161D2C | 卡片 / 列表容器 |
| `--elevated` | #1E2A3D | 中性标签底 / 表头底 / 悬浮层 |
| `--text` | #E6EAF2 | **主标题 / 正文 / 数值** |
| `--sub` | #9AA3B8 | **副标题 / 次要文字 / 表头** |
| `--note` | #78849E | **注释 / 占位符 / 辅助说明** |
| `--accent` | #3D7EFF | 强调 / 选中 / 进行中 / 链接 |
| `--ok` | #22C55E | 达标 / 完成 / 买入 |
| `--warn` | #F59E0B | 待审批 / 移动止盈 |
| `--danger` | #E5484D | 预警 / 待处理 / 卖出 / 角标底 |
| `--line` | #2A3550 | 分割线 / 控件描边 / 表格行分隔 |
| 引擎蓝 / 引擎紫 | #3D7EFF / #8B7CF6 | Codex / DeepSeek 引擎标识 |

用法约定：主标题用 `--text`；副标题用 `--sub`；注释用 `--note`；状态类一律用状态色（ok / warn / danger / accent），**不用状态色表达装饰**。

## 四、胶囊标签（统一样式，唯一模板）

| 形态 | 样式 |
|---|---|
| 基础 | 字号 **24px**（12px 逻辑）· 字重 **500** · 圆角 **4px** · 内边距 **6px 16px**（物理） |
| 中性 | `--elevated` 底、无描边（版本号 / 已冻结 / 通用信息） |
| 状态（描边） | **描边 2px + 同色文字**：达标绿 #22C55E / 待审批黄 #F59E0B / 预警红 #E5484D / 进行中蓝 #3D7EFF |
| 强调（填充） | 填充底色 + 白字：accent 蓝（Codex / 进行中强调）、ok 绿（已发布 / 完成） |
| 引擎 | 蓝 #3D7EFF（Codex）、紫 #8B7CF6（DeepSeek），描边样式 |
| 数字角标 | 红底白字 #E5484D · 圆角 **10px** · 字重 **600** · 内边距 **2px 12px** · 用于未读数 / 待处理计数 |

方向语义（交易/变更类）：**买入 = 绿填充**、**卖出 = 红填充**（跟随色板语义，全局一致）。

### 4.1 标签颜色使用规范（语义映射表，全系统一，禁止随意取色）

| 语义 | 颜色 | 形态 | 典型文案 |
|---|---|---|---|
| 完成 / 达标 / 成功 / PASS / 已发布 | **ok 绿 #22C55E** | 描边（强调可填充） | 已完成、已发布、达标、通过 |
| 进行中 / 执行中 / 选中 / 处理中 | **accent 蓝 #3D7EFF** | 描边（强调可填充） | 进行中、执行中、处理中 |
| 待审批 / 待处理 / 待确认 / 待审核 | **warn 黄 #F59E0B** | 描边 | 待审批、待处理、待确认 |
| 预警 / 失败 / 超限 / 危险 / 卖出 | **danger 红 #E5484D** | 描边（角标=红底白字填充） | 预警、失败、超限、卖出 |
| 中性信息 / 版本号 / 已冻结 / 通用 | **elevated 底 #1E2A3D** | 中性填充、无描边 | v1.0.0、已冻结、信息 |
| 引擎标识 | Codex **蓝 #3D7EFF** / DeepSeek **紫 #8B7CF6** | 描边 | Codex、DeepSeek |
| 方向语义 | 买入=**绿填充** / 卖出=**红填充** | 填充 | 买入、卖出 |
| 产品专属扩展 | 子品牌自定义 accent 色（如金色） | 描边 | 产品专属状态，须在总纲登记 |

**使用规则**：① 颜色必须对应语义，禁止为美观换色；② 同一语义全系统一颜色；③ 状态色只表达状态、禁止装饰性使用；④ 新语义需新增颜色时走范式登记流程，不得擅自造色。

### 4.2 多标签排列规范（单元格 / 区域多个标签时）

| 规则 | 内容 |
|---|---|
| 排列顺序 | **属性类在前、状态类在后**（例：`开源` → `待核`、`持牌` → `部分持牌`） |
| 标签间距 | **8px**（物理，逻辑 4px）；一行放不下时换行，行距 **8px** |
| 数量上限 | 单元格 / 区域内默认 **≤2 个**；超出折叠为 `+N`（中性角标，悬停 / 点击展开全部） |
| 颜色 | 各标签独立按 4.1 语义表取色，**不因并排而改变颜色** |
| 对齐 | 同一行多标签垂直居中，与相邻文字基线对齐 |

**属性类标签语义登记**（事实属性，非状态，一律中性 elevated 底）：

| 属性语义 | 示例文案 | 形态 |
|---|---|---|
| 事实属性 | 开源、持牌、跨境、DeFi、质押、CEX | 中性 elevated 底、无描边 |
| 待核实属性 | 待核、待验证、部分持牌、待确认 | warn 黄描边 |

> 属性标签只描述客观事实，不表达好坏；一旦转化为状态（如"已核验"）即按 4.1 状态语义取色（ok 绿）。

## 七、计量单位（阿拉伯数字 + 英文缩写）

- ≥1000 使用英文计量单位：**K（千）/ M（百万）/ B（十亿）**
- 保留 **1 位小数**；单位紧跟数字，字号 24–32px、字重 600、`--accent` 色
- 数字一律 `tabular-nums` 等宽对齐（例：999、1.2K、3.4M、1.0B）

## 八、滚动条

| 元素 | 规范 |
|---|---|
| 形态 | 细窄 overlay 滚动条，**不占布局宽度**；无滚动内容时自动隐藏 |
| 宽度 | **6px**（物理，逻辑 3px） |
| 轨道 | 透明（`transparent`） |
| 滑块（默认） | `--line` #2A3550 · 圆角 **3px** |
| 滑块（悬停 / 拖动） | `--accent` #3D7EFF |
| 组件级变体 | 特定列表/指示类组件可使用 **3px 蓝色渐变细竖线**（accent 渐变）作为悬浮指示条，属组件级扩展，不改变全局滚动条形态 |

## 十、缩放规则

- 横屏：`字号 = 基准值 × min(目标宽 ÷ 2560, 目标高 ÷ 1600)`
- 竖屏：`字号 = 基准值 × min(目标宽 ÷ 1600, 目标高 ÷ 2560)`
- 胶囊内边距 / 行高 / 间距随字号**等比缩放**，不单独另定尺寸。
- 应用图标（§十三）基准边长 128px 随同一公式缩放。

## 十一、违禁（禁止项）

- 禁止更换字体（中文 / 英文 / 数字 / 等宽四类已锁定）
- 禁止数字不用 `tabular-nums` 对齐
- 禁止在字号阶梯外自定义新字号
- 禁止自造颜色（必须取自§三色板）
- 禁止改动胶囊圆角（4px）、字重（500）、角标圆角（10px）
- 禁止用状态色做装饰性用途
- 禁止应用图标内加文字（桌面图标下已有应用名，图标内文字属冗余）
- 禁止应用图标白底 + 白 logo / 深色底 + 深色 logo（对比失效）
- 禁止应用图标缩放变形 / 拉伸（logo 与底框比例锁死，见§十三）
- 禁止应用图标加阴影 / 光晕 / 杂色底纹（沿用品牌规范：logo 无阴影无光晕）

## 十三、APP 应用图标（Launcher / App Icon）

> 桌面 / 安装包 / 应用商店中的应用图标。唯一图形元素 = 透明底头盔 logo（品牌库 `ultima-logo/helmet.png`，无阴影无光晕）；**图标内不加任何文字**（桌面图标下方已有应用名）。

### 13.1 形态（唯一模板，禁止另造）

| 元素 | 规范 |
|---|---|
| 底色 | `--bg` #0F1420 纯色（深色主题品牌底） |
| 主图形 | 透明底头盔 logo（helmet.png），**居中** |
| logo 高度 | = 图标边长 × **60%**（左右各留 20% 安全区，防系统蒙版裁切） |
| 圆角 | = 图标边长 × **22%**（系统蒙版可最终裁定，设计稿按此渲染） |
| 文字 | **禁止**（logo + 文字组合仅用于品牌区/物料，见品牌规范 2.2） |
| 装饰 | 禁止阴影 / 光晕 / 渐变底纹 / 杂色噪点；产品专属底色（如金色主题）须在品牌库 README 登记后可用 |

### 13.2 尺寸体系（物理基准 2560×1600）

| 场景 | 尺寸 | 说明 |
|---|---|---|
| 设计稿基准 | 边长 **128px** | 缩放公式同 §十（横 `×min(w/2560,h/1600)` / 竖 `×min(w/1600,h/2560)`） |
| HarmonyOS 应用图标 | **288×288 px** | AppScope/resources/base/media/app_icon.png（前台图标） |
| Web favicon | 32×32 / 64×64 | **透明底头盔**（不带底框，网页场景） |
| 桌面 / 安装包主图 | 512×512 | 深底圆角 22% |
| 应用商店宣传图 | 1024×1024 | 深底圆角 22% |
| 自适应图标（Android 类） | 前景 432×432、安全区 66% | 前景 = 头盔，底 = 深色 #0F1420 |

> 任意目标尺寸下，比例一律按 13.1 换算：`圆角 = 边长×22%`、`logo 高 = 边长×60%`、`居中`。

### 13.3 变体规则

| 场景 | 形态 |
|---|---|
| 桌面 / 安装包 / 商店 | **深底 #0F1420 + 头盔**（唯一主形态） |
| Web favicon / 小尺寸控件 | 透明底头盔（复用品牌库悬浮球同源资产） |
| 浅色底页面（如文档封面） | 允许浅底深标变体，但**必须**在品牌库登记后使用，主形态不变 |
| 产品专属主题 | 子品牌可换底色（如金色），须登记品牌库 README，结构（深底 + 居中头盔 + 无文字）不变 |
