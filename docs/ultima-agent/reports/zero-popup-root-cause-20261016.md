# 弹窗根因深度分析（零弹窗绝对纪律 N7 · 后台运行强要求）

- **版本**：v1.0 · 2026-10-16
- **性质**：技术根因分析报告（弹窗产生的全部可能原因 + 根治手段 + 验收核查清单；为 ops-selfcheck §3 零弹窗绝对纪律的实现层依据）
- **触发**：用户定稿"前台不要展示任何弹窗，任何弹窗闪一下都不行；强烈要求它在后台运行"
- **结论先行**：弹窗根因分**六层十二类**；**"启动点加 CREATE_NO_WINDOW"防不住弹窗**（官方已证实 DETACHED_PROCESS 子进程仍可能弹窗；登录态计划任务必然闪窗；GUI 程序标志无效；孙进程不继承标志）。要真正零弹窗，必须**链路级根除**：执行器统一 pythonw + 显式标志 + 消灭中转层 + 孙进程穿透控制 + 计划任务非交互会话 + 崩溃/提权弹窗抑制 + 运行期窗口枚举验收。

## 1. 弹窗根因全景（六层十二类）

| 层 | 类别 | 根因机制 | 典型实例 | 现有 N7 手段是否覆盖 |
|---|---|---|---|---|
| A 进程创建层 | A1 控制台子系统进程 | CUI 子系统可执行文件（python.exe/cmd.exe/bat/普通 exe）启动即新建可见控制台窗口；父无控制台时尤其如此 | python 脚本黑框、cmd /c 黑框 | ✅ 覆盖（pythonw/CREATE_NO_WINDOW） |
| A 进程创建层 | A2 GUI 子系统自建窗口 | GUI 程序自己 CreateWindow/MessageBox；控制台标志管不住 | 更新器、安装器、错误对话框 | ❌ 需白名单/隔离 |
| A 进程创建层 | A3 标志的固有局限 | ① DETACHED_PROCESS 单独使用仍可能弹窗（Python bpo-41619 官方确认）；② CREATE_NO_WINDOW 只对控制台进程有效、对已有关联控制台进程无效；③ **间接子进程（孙进程）不继承标志**；④ PowerShell 不尊重 CREATE_NO_WINDOW（需 -WindowStyle Hidden 且登录态仍会闪） | python -c "os.system(...)" 再派生 | ❌ 需孙进程穿透控制 |
| A 进程创建层 | A4 新式终端关联 | Windows 11 默认终端为 Windows Terminal，控制台进程启动可能触发 WT 窗口弹出，CREATE_NO_WINDOW 被忽略 | 控制台子进程闪出 Windows Terminal | ❌ 需验证 + 非交互会话兜底 |
| B 任务计划层 | B1 登录态任务必闪 | 计划任务"只在用户登录时运行"=交互会话启动，**必然闪一下窗口**（微软官方 + 论坛实证） | schtasks 定时任务闪窗 | ❌ 需改"不管用户是否登录都要运行" |
| B 任务计划层 | B2 执行器用错解释器 | 计划任务 Action 直接指向 python.exe/cmd.exe/bat | 定时任务黑框常驻/闪现 | ✅ 覆盖（pythonw） |
| C 包装中转层 | C1 裸系统调用/中转 | os.system()/os.popen()/bat 中转/WMI（wmic 控制台程序）逐层新建控制台 | 脚本里 os.system 每调用闪一次 | ✅ 覆盖（禁裸调用） |
| C 包装中转层 | C2 外层隐藏内层弹 | powershell -WindowStyle Hidden 只隐藏自身主窗口，Start-Process 内层子进程不带标志仍弹 | ps1 里 Start-Process python 弹窗 | ❌ 需内层显式标志 |
| D 程序自身层 | D1 崩溃报告弹窗 | 进程崩溃触发 WER（werfault.exe）"程序已停止工作"弹窗；后台任务崩溃时闪现 | 后台脚本异常退出弹 WER | ❌ 需抑制/捕获 |
| D 程序自身层 | D2 提权与安全拦截弹窗 | 程序请求管理员权限 → UAC 弹窗；首次运行被杀软/防火墙拦截弹窗 | 后台任务触发 UAC | ❌ 需范式禁止后台提权 |
| E 会话桌面层 | E1 交互会话可见 | 进程在用户交互桌面（session 1+ / WinSta0）运行，一切窗口可见 | 登录态计划任务、交互启动 | ❌ 需非交互会话兜底 |
| F 时序层 | F1 一闪而过 | 窗口创建→进程快速退出→窗口短暂出现后消失（秒退脚本最典型）；conhost 启动滞后于程序退出 | python 脚本秒退闪黑框 | ⚠️ 运行期枚举可捕获 |

**关键结论**：
1. **"闪一下"的主要来源** = A1（秒退脚本新建控制台）+ B1（登录态计划任务）+ F1（conhost 滞后）——三者叠加就是 Top 阶段看到的"终端窗口跳出来闪几下再消失"。
2. **"执行一个终端窗口不消失"** = 父进程本身带控制台（python.exe 启动的守护器/派发器常驻），子任务共用同一可见黑框——根治点是**守护器本身用 pythonw**。
3. 单点加标志（A 层）只能解决 A1/A2 一部分；B/C/D/E 层漏一处就破功。

## 2. 根治手段（按可靠性排序，落地到链路）

| 序 | 手段 | 解决的问题 | 落地位置 |
|---|---|---|---|
| 1 | **执行器统一 pythonw.exe**（GUI 子系统，无控制台）：守护器/派发器/看门狗/探活器/一切常驻进程禁止用 python.exe | A1、B2、常驻黑框 | 启动脚本、计划任务 Action、spawn 助手 |
| 2 | **subprocess 一律显式 `creationflags = CREATE_NO_WINDOW(0x08000000) | DETACHED_PROCESS(0x00000008)`**，shell=False、数组参数 | A1、A3（直接子进程） | 统一 spawn 助手 |
| 3 | **消灭中转层**：禁裸 os.system/os.popen/bat 中转/裸 cmd /c/WMI；需要 shell 能力一律走 spawn 助手 | C1 | 代码规范 + 审计反推 |
| 4 | **孙进程穿透控制**：spawn 助手强制逐层传递标志；审计时对"脚本内再派生"场景专项穿透测试（故意派生孙进程验证 0 窗口） | A3、C2 | 审计专项 + 测试用例 |
| 5 | **计划任务"不管用户是否登录都要运行"**（非交互会话，微软官方：非交互会话任务永不显示为桌面窗口）+ Action 执行器 pythonw | B1、E1（计划任务链路） | 任务创建规范 |
| 6 | **GUI 程序白名单/隔离**：后台链路禁止启动会自建窗口的 GUI 程序；确需的（如 WebView2 宿主）仅在宿主壳受控窗口内运行，其他一律拒绝 | A2 | 派发器禁止清单 |
| 7 | **WER 崩溃弹窗抑制**：后台链路不裸跑易崩程序；异常统一捕获转日志（失败回执 I3 结构化），不触发 werfault 弹窗 | D1 | 执行器 try/except 全包 |
| 8 | **后台禁止自动提权**：任何后台任务不得请求管理员权限（UAC 弹窗违背零弹窗）；提权必须人工授权，进审计事件 | D2 | 范式红线 |
| 9 | **运行期窗口枚举验收（N7 已立）**：MainWindowHandle + 可见窗口 + 窗口创建事件监听全程计数 0（宿主 GUI 除外），"一闪而过"也被捕获 | 全层 | 验收 Gate |
| 10 | **终极兜底（可选演进）**：关键后台链路注册为 Windows 服务（session 0 无交互桌面）——与宿主交互部分例外保留 | E1 | 阶段二/三评估 |

## 3. 后台运行强要求（用户定稿）

- Ultima 全部派发/看门狗/探活/执行链路**必须后台运行**：不落用户交互桌面、不产生任何可见窗口、不打断用户操作。
- 后台运行与"宿主壳 GUI"并存：宿主壳（悬浮球/组合窗口）是产品界面，允许且必须显示；**除宿主壳外的一切进程零弹窗**。
- 弹窗 = 缺陷：任何启动点或运行期窗口闪现，一律判失败并生成修正任务（已有 N7）。

## 4. 验收核查清单（审计/自检执行）

1. 全部启动点反推清单（含派发脚本、探活脚本、计划任务 Action）——逐点核对：pythonw / 显式标志 / 无裸中转。
2. 进程属性核对：目标进程无控制台（MainWindowHandle=0、无 conhost 关联）。
3. 运行期窗口枚举：任务执行全程计数 0（含窗口创建事件监听，捕获一闪而过）。
4. 孙进程穿透测试：构造"脚本内再派生"用例，验证孙进程仍 0 窗口。
5. 计划任务核对：Action=pythonw、安全选项=不管用户是否登录都要运行（或明确豁免记录）。
6. 崩溃路径核对：异常是否统一捕获转日志，无 WER/UAC 弹窗风险。
7. 禁项核对：代码中无 os.system/os.popen/裸 cmd/裸 bat/WMI 调用。
