# 动效规范（Motion Director）

- **版本**：v1.0 · 2026-10-16
- **性质**：范式文件（冻结区，变更走评审）
- **来源**：AI 界面动效调研（VP0 / emil-kowalski / Mico / ChatGPT dots）

## 1. 定位：动效是"智能体在干什么"的可见性系统，不是装饰

动效的首要职责是让用户看懂"智能体在做什么"——具名状态胜于抽象加载。

## 2. 活动可见性（四状态四动效）

| 状态 | 动效 | 说明 |
|---|---|---|
| 思考中 | 首 token 前的思考点/呼吸 | 极短，不抢 |
| 执行中 | **具名进行中状态**（"正在搜索网页" > 三个点） | 可叙述的等待是被原谅的等待 |
| 长任务 | 计时 / 进度 | 报进度 |
| 完成 | 入场动画（非打字机回放） | **永不回放已完成文本为打字机效果** |

对应异步三拍：接单（应答动效）→ 干活（具名进行中 + 进度）→ 交活（窗口入场）。

## 3. 时长档（动效令牌）

| 档位 | 时长 | 用途 |
|---|---|---|
| 即时反馈 | 100–150ms | 按钮/开关/颜色变化 |
| 状态变化 | 200–300ms | 菜单/提示/切换 |
| 窗口/抽屉 | 200–500ms | 弹窗进出 |
| 硬上限 | **<300ms**（主流） | 超过则迟钝 |

## 4. 缓动档（动效令牌）

| 方向 | 缓动 |
|---|---|
| 入场 | ease-out（快起缓落） |
| 出场 | ease-in（加速离开） |
| 屏上 | ease-in-out |
| 循环氛围 | sine（无缝） |

元素出现从 `scale(0.95)` 起（不抖）；加 `will-change`。

## 5. 流式/生成式内容

- 内容到达：入场（fade + 位移）；容器高度平滑缩放，不硬切。
- 组合窗口改参数/换主题应平滑过渡（对话即操作的反馈）。

## 6. 语音状态可视化

- 倾听 / 思考 / 说话三状态，用悬浮球呼吸 / 雷达波 / 音浪表达（绑定语音 IO 状态机）。
- 避免真人脸（恐怖谷）；用几何/光效而非拟人形象。
- 参考：Microsoft Copilot Mico、OpenAI ChatGPT dots。

## 7. 克制原则

- 动效服务理解，不服务装饰；高频交互轻，稀有时刻（首次/庆祝）可 delight。
- 智能体按场景从令牌选值，**动效库给条目，不固定唯一效果**（固定动效＝套壳应用）。
