## 1. 7 环标准交互流程

智能体与用户交互前，必须按此流程**完整走一遍**，不得跨过或随意执行：

```
① 意图识别 → ② 领域定义 → ③ 排版组合 → ④ 样式 → ⑤ 动效 → ⑥ 呈现窗口 → ⑦ 语音汇报
```

| 环 | 职责 | 落点 |
|---|---|---|
| ① 意图识别 | 听懂意图，含隐含补全（今天=本地日、Top10=热度前10、默认不打断） | 服务器 L1 |
| ② 领域定义 | 知道该域包含哪些内容 | 服务器 L2 |
| ③ 排版组合 | 内容类型判定 + 三层组装 + 尺寸自适应（scene-orchestrator） | 服务器 L4 |
| ④ 样式 | ui-kit 令牌/组件取值 | 服务器 L4 |
| ⑤ 动效 | motion-director 按场景选动效 | 服务器 L4 |
| ⑥ 呈现窗口 | 组合窗口渲染（薄壳承担渲染） | 终端壳 |
| ⑦ 语音汇报 | 像人一样总结 + 语音输出（CV3） | 服务器 L6 + 终端壳 |

## 2. 对话即操作（标准交互循环）

窗口控件是给智能体编排的积木，**不是给用户点的**；语言是唯一操作入口，鼠标点击退出操作。

```
调整（说话）→ 重呈现（窗口/语音更新）→ 征询（"你觉得怎么样？"）→ 确认 → 待命（"有新需求再喊我"）
```

适用：调透明度、换主题、插队任务、取消任务——全部用说话完成。

## 3. 异步交付三拍

| 拍 | 行为 | 时长感知 |
|---|---|---|
| 接单 | "好，我去整理，稍等" | 秒级：静默即可 |
| 干活 | 后台执行，长任务报进度 | 分钟级：先应答；长任务报进度 |
| 交活 | 窗口 + 语音交付 | 完成后立即 |

## 4. 汇报范式三规则（像人一样总结）

1. **结论先行**："20 个环境需求，1 个异常"——先给总数和判断。
2. **异常优先 + 聚合压缩**：合格项合并一句，禁止逐条朗读（19 个合格不重复报）。
3. **按需下钻**：聚合 ≠ 丢细节，可展开明细（Top3 展开，其余折叠可下钻）。

## 5. 任务队列管理

- 耗时活自动拆任务入队。
- 可查：总结式列出（结论先行 + 分类聚合 + 可下钻）。
- 可调：插队 / 优先级 / 取消——全用说话，调整后重呈现确认。

## 6. 外部数据源容错（key 不卡死，四层）

| 层 | 策略 |
|---|---|
| 凭证层 | 本地加密凭证中心 + 多 key 轮换 + 缺失主动提示不阻塞 |
| 通道层 | 官方 API → 备用 key → 公开端点 → 第三方聚合 → 最近成功缓存，逐级降级 + 来源标记 |
| 运行时 | 超时重试上限 + 错误分类处理（401/429/403）+ 熔断 |
| 结果层 | 宁给缓存 + 说明，绝不假装成功、绝不卡死 |

> 同类：**知识也不卡死**——执行遇缺口主动检索教程（OS-Symphony Search-as-a-Tool 借鉴），见 references。

## 7. 交互闭环预演（强制，I12）

新交互（向导/弹窗/提交/队列调整）交付前必须预演一遍"用户路径"，覆盖**无反应 / 超时 / 失败态**：

1. **路径预演**：按 7 环流程走一遍——意图→领域→排版→样式→动效→呈现→汇报，确认每环有产出。
2. **失败态交代**：每个关键动作（提交/播放/搜索/调整）预演失败分支——无反应时给什么反馈、超时给什么、失败给什么；禁止"点了没反应"裸奔（Top 阶段 brick-config-wizard 九步走完点提交无反应的教训）。
3. **异步三拍衔接**：长任务必须走接单→干活→交活，不能静默卡死。
4. **预演产出**：交互卡（用户路径 + 每步反馈 + 异常分支）随交付物一起评审。
