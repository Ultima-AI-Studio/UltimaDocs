# 知微 V1.0 产品方案（可直接复制使用）

产品名称：知微｜银发AI守护
归属：Ultima AI Studio
版本：V1.0（首发正式版）
产品定位：面向老年群体的陪伴式云端AI反诈风险解读工具，公益免费，支持上架安卓应用商店，无商业变现。

## 一、产品核心理念

跳出行业主流反诈安防“拦截、管控、限制用户”的设计思路。

市面上同类产品逻辑：发现风险→强制拦截、拉黑阻断、替用户做决定；
本产品逻辑：发现风险→把风险讲清楚，决策权完整交给老人。

我们不做风险的“拦阻者”，做老人看得清、听得懂、低抵触的AI风险讲解员。

核心一句话：传统反诈产品拦风险，知微V1.0帮老人看懂风险。

## 二、产品愿景

专为老年人认知习惯、视力与听力特点打造一套风险辅助体系。在老人接触诈骗话术、虚假宣传、诱导信息的第一时间，以超大文字、舒缓清晰语音、通俗直白的解释拆解骗局；搭配云端AI语义能力识别持续变形、规避关键词的新型骗术。全程无强制阻断、不擅自拉黑、不替老人选择，以温和低压迫的方式，提升老年人自身识别骗局的能力。

## 三、产品关系说明

知微是独立C端产品，不属于 Ultima Sentinel，拥有独立产品目标、交互体系、分发路径。

由 Ultima Sentinel 持续生产、评审、迭代风险规则库与反诈知识库，策略托管在远端服务，支持无感下发更新。

Ultima Sentinel 主线业务为企业侧安全审计（PDPA合规审计、合约审计、渗透测试），银发反诈规则是其独立产出成果，专供本产品使用，不对外单独售卖。

## 四、目标用户

国内安卓老年机用户；机型性能偏弱、内存小，视力、听力退化，对网络骗术辨别能力不足；普遍反感强制弹窗、强行断网、子女远程管控类软件，容易抵触防护软件、主动卸载或者关闭权限。

## 五、V1.0 核心设计原则（差异化根基）

1. 决策归用户原则：产品仅识别、解释风险，绝不自动拦截、强制退出、拉黑号码，所有操作动作必须由老人主动点击确认。
2. 低压迫适老体验优先：弹窗无刺耳警报、不频繁轰炸，文案避免恐吓风格；字号最大化、播报语速放缓，降低老年人紧张与抵触情绪。
3. 轻量化硬约束：APP资源占用低，适配老旧低配安卓机型；AI大模型全部部署云端，手机本地不运行LLM，保证包体小巧、运行流畅。
4. 隐私最小化原则：本机风险记录默认仅保存在本地；云端AI研判，必须老人手动确认提交，仅上传脱敏文本摘要，禁止静默、自动抓取页面原文。
5. 规则优先、AI增强：本地规则引擎作为稳定底座，断网环境下依旧可以正常防护；云端AI语义能力为V1.0原生标配，专门识别变种、谐音、改写的新型诈骗话术，弥补关键词匹配短板。
6. 持续无感更新：风险规则后台空闲时段静默拉取更新，不打扰老人使用手机，不弹出更新通知。
7. 适老化语音基准：复用系统自带TTS，不内置语音包；播报节奏舒缓，语句简短；播报完成立刻释放语音资源，不占用内存。
8. 无管控焦虑：不默认开启远程监护；监护人模块是可选模块，开启必须老人主动授权，老人拥有随时关闭的权利，避免老人产生被监视感。

## 六、V1.0 完整功能结构（全部为V1.0内置能力）

### 一、实时风险识别与陪伴解读（核心主线功能）

1. 页面文本风险识别

扫描APP内、浏览器、聊天软件页面文本，命中规则库风险时，弹出全局提示卡片：超高对比度、超大字体、简洁排版。

卡片固定两个基础选项：
- ✅ 继续浏览
- ⚠️ 我要退出

同步触发TTS语音朗读这条风险解释，直白口语化表达，避免专业术语。

当规则判定“疑似、无法完全确定”，卡片增加第三个主动选项：【让AI帮我看一看】

只有老人主动点这个按钮，才会把脱敏摘要送到云端AI做语义研判，返回AI解读，继续TTS朗读。

AI结论标注：AI辅助研判，仅供参考。

2. 剪贴板链接自动识别

复制短信、聊天里的链接时静默识别钓鱼/高危链接；弹窗+语音提醒，同样支持主动发起AI核验。

3. 风险话术分层解读体系

一层：基础版（规则自带）：一句话直白警示；
二层：增强版（AI生成）：讲清楚骗子想干什么、会怎么骗你、会造成什么后果，老人更容易理解套路。

家属可以在设置页自由切换【固定文案模式 / AI通俗解读模式】；关闭AI模式，完全离线可用。

### 二、云端AI反诈套件（V1.0原生标配，云端推理，本地无大模型）

1. 变种话术语义研判：识别拆字、谐音、分段、换说法规避关键词的新型骗局，弥补静态规则滞后性。
2. AI反诈语音问答助手：独立入口，老人直接语音提问（例如：屏幕共享危险吗？对公转账是骗局吗？），云端RAG调取反诈知识库回答，回答自动TTS播报。
3. AI话术润色：把标准化风险提示转化为老年人更容易听懂的口语，不改动风险判定本身，只优化表达。

约束：网络断开时，所有AI入口置灰不可点击；基础规则预警、语音解读完全不受影响。

### 三、设置中心（极简，给家属辅助配置，不给老人增加负担）

1. 语音设置：语速调节、音量跟随系统、开关AI润色模式
2. 提醒强度设置：提示弹窗敏感度（降低误报，减少打扰）
3. 监护人授权开关（默认关闭）
   - 开启必须老人主动同意授权；
   - 授权后监护人仅查看结构化风险日志（时间、风险类型、老人选择），看不到聊天原文、截图；
   - 老人随时可以一键关闭授权，收回查看权限。
4. 白名单配置入口（家属协助添加可信APP），减少熟人、正规商家带来的误报骚扰。

### 四、本地风险日志（本机存储，默认不上传）

记录识别到的风险条目，仅保存结构化摘要，不保存原文；支持老人、家属自行查看；无自动上传。

> 📌 V1.0 明确不做（砍掉，保证体验聚焦，不堆砌功能）
> - 来电号码识别、通话监听识别（放到V2迭代）
> - APP本地安全扫描（放到V2迭代）
> - 自动线索上报、社区协同模块（预留架构接口，默认不打包，遵循“栽下梧桐树”思路）

## 七、协同理念：产品优先，静待认可（不主动申报官方认证）

采用“酒香不怕巷子深，栽下梧桐树，引得凤凰来”思路。

前期不主动跑官方申报、专项审核流程。重心全部打磨这套差异化陪伴式反诈体验，控制误报、降低老人抵触感，依靠家属、社区自发口碑扩散。

如果后续反诈部门主动接洽认可，我们再按需开启预留的协同模块；现阶段不把协同能力塞进V1.0，避免功能臃肿、逻辑复杂。

对外宣传口径克制：不宣称官方合作，不使用官方背书。

## 八、分发与运营规则

1. 支持上架安卓应用商店，同时保留定向分发渠道；定向版本告知使用者禁止二次分发。
2. V1.0主推包 = 精简体验版（上面全部V1.0内置能力）：本地规则预警、云端AI反诈、TTS语音解读、链接识别、日志、设置、可选监护人模块。
3. 不做繁杂分支版本，V1.0聚焦一套扎实体验，优先跑通用户感受。

## 九、合规与上架说明

1. 统一提示口径：所有风险提示标注【疑似风险】，AI输出标注【AI辅助研判，仅供参考】；绝不使用确定性定性话术。
2. 宣传禁止绝对化承诺：不说100%防骗、杜绝诈骗；主打差异化卖点：陪伴式AI反诈解读工具，不强行拦截、帮老人看懂骗局。
3. 首次启动弹窗用户协议与免责声明，需要主动勾选同意：告知工具仅为辅助，无法覆盖全部风险，用户自主决策带来损失由本人承担。
4. 权限说明清晰透明：无障碍权限、网络权限，逐条解释用途，不隐瞒。
5. Sentinel配套建立误报申诉复核通道，持续迭代规则库，持续压低误报，这是体验扎实的核心根基。

## 十、和市面上所有银发安防产品的核心差异化总结

| 市面主流银发反诈/安防 | 知微 V1.0 |
| ---- | ---- |
| 底层思路：风控管控，优先拦截、限制、拉黑 | 底层思路：陪伴解读，优先讲清楚风险，决策权交给老人 |
| 交互：强恐吓、强制阻断、频繁告警轰炸，老人容易反感卸载 | 交互：低压迫温和提示，语速舒缓、大字易懂，减少抵触 |
| AI用法：大多是噱头，AI用来自动拦截判定 | AI用法：辅助看懂变种话术，AI只做解读，不替用户做阻断决定 |
| 监护默认开启，偏向子女远程管控老人 | 监护能力默认关闭，老人掌握授权开关，尊重老人隐私和自主感 |
| 依赖关键词库，变种骗术很容易绕过 | 本地规则兜底 + 云端AI语义识别双引擎，应对不断变形的骗局 |
| 产品目标：拦住诈骗 | 产品目标：教会老人识别诈骗 |

## 十一、产品局限（清晰对外告知）

1. 无法识别图片内文字、二维码背后风险；
2. 无法识别AI换脸、AI语音仿冒熟人视频诈骗；
3. 老人主动拨打骗子电话、主动添加好友、主动扫码的行为无法拦截识别；
4. 新型诈骗套路存在规则、AI知识库更新时差，存在漏判；
5. 系统权限被安卓系统后台清理后，防护能力暂停；
6. TTS语音依赖手机系统语音包，缺少中文语音包时仅保留文字提示；
7. AI研判依赖网络，断网时AI问答、AI语义核验不可用，基础规则防护正常工作；
8. AI存在误判概率，所有AI结果仅作参考。

## 十二、价值总结

知微不是一个看管老人的安全闸门，而是一个耐心、看得清、听得见的AI风险讲解员。依托Sentinel持续迭代的规则库，搭配云端AI语义能力识别变种骗局，配合大字提示与语音朗读，在老人踩坑之前把风险讲明白，把选择权交还老人，温和克制地完成安全守护。

## 附录 B：方案内已明确、需在后续文档中继承的硬约束

1. **决策权归用户**：不得出现任何自动拦截、强制退出、自动拉黑逻辑（技术方案与代码评审均按此判定越界）。
2. **本地不跑 LLM**：手机端零大模型依赖，AI 能力一律云端；技术方案须给出断网降级路径。
3. **隐私最小化**：云端研判仅接受老人手动触发 + 脱敏摘要，禁止自动抓取页面原文、禁止静默上传。
4. **监护人模块默认关闭且可随时关闭**：授权链路必须由老人本人完成。
5. **V1.0 范围冻结**：来电/通话识别、APP 本地扫描、线索上报与社区协同不进 V1.0（仅可预留接口，默认不打包）。
6. **对外口径**：风险提示一律【疑似风险】，AI 输出一律【AI辅助研判，仅供参考】；禁止 100% 防骗类绝对化承诺。
