## 产品要点（详见方案）

- **不做拦阻者**：不自动拦截、不拉黑、不强制退出、不替老人决策；只识别、讲清、给老人选。
- **双引擎**：本地规则引擎兜底（断网可用）+ 云端 AI 语义研判（识变种 / 谐音 / 拆字话术）；**手机端零 LLM**。
- **适老交互**：超高对比度大字卡片、两三个大按钮、系统 TTS 舒缓朗读，无刺耳警报。
- **隐私最小化**：日志仅存本机、仅存结构化摘要；云端研判须老人手动触发 + 只传脱敏摘要。
- **监护人可选**：默认关闭，老人授权，可随时一键收回，只看结构化日志。
- **V1.0 不做**：来电 / 通话识别、APP 本地扫描（留 V2）；线索上报与社区协同（仅预留接口，默认不打包）。

## 与 UltimaSentinel 的关系

知微是**独立 C 端产品**，不隶属 Sentinel。Sentinel 的主线是企业侧安全审计；它为本产品**持续生产、评审、迭代风险规则库与反诈知识库**，策略托管远端、无感下发。银发反诈规则是 Sentinel 的独立产出，专供本产品，不对外单独售卖。
