# 03-时序流程 · UltimaRadar

> 服务类时序契约：启动 → 运行 → 关闭 + 容灾。权威实现：本地 `backend/main.py`（网关）、VPS `deploy/ultimaradar-server/main.py`（采集服务）。

## 〇、双端拆分后的启动时序（2026-10-18）

```
VPS 采集服务（systemd ultimaradar）
  ├─ 读 .env（ULTIMARADAR_API_TOKEN / HELIUS_API_KEY）
  ├─ init_db() 建表（全量表，首启空库）
  ├─ API 监听 0.0.0.0:8721（除 /api/health 外需 X-API-Token）
  └─ 后台线程：采集轮询 / pumpfun / paper 引擎 / 备份 / 保留清理（health 自愈监管）

本地壳（Electron）
  └─ 守卫 spawn python backend/main.py（隐藏窗口，防弹窗）
       └─ gateway.py 监听 127.0.0.1:8721
            ├─ /api/health → 本地健康 + VPS 连通状态（up/down/unconfigured）
            ├─ GET /api/*  → 转发 VPS（带 token）→ 成功写 local_cache.db；失败回退缓存(stale)
            └─ POST /api/* → 转发 VPS（写操作，不缓存）
Electron 前端加载 index.html → 轮询本地 8721（15s 默认）
```

## 一、启动时序（采集版，历史保留：见 deploy/ultimaradar-server）

```
Electron 启动
  └─ 守卫 spawn python backend/main.py（隐藏窗口，防弹窗）
       ├─ init_db()                   建表 + 迁移（幂等）
       ├─ 首轮错峰 sleep(60s)         等首轮写库高峰
       ├─ 首轮 pipeline（后台线程）
       │    ├─ import_addresses → 地址导入
       │    ├─ 全量清洗（后台线程，614 地址级，RPC 多 key 轮换）
       │    ├─ 评分 → Top10
       │    ├─ 快照采集（watchlist 币种，DexScreener）
       │    ├─ 信号融合（GMGN/MadeOnSol/pumpfun/共振/热度）
       │    ├─ 热度自动并入 watchlist（≤2/轮）
       │    └─ 写库
       ├─ API 服务 http.server 监听 127.0.0.1:8721
       └─ pumpfun 独立采集线程（60s 轮询）
Electron 前端加载 index.html → 轮询 API（15s 默认）
```

## 二、运行循环

- 主循环：`pipeline_once()` 每 60s 一轮（前端运行设置可调 15/30/60/120s——注意：改的是**前端轮询**，后端 60s 固定）。
- 后台任务：全量清洗（启动/手动添加时）、新闻热度懒采集（API 缓存空时，15min TTL）、logo 兜底（Helius→Birdeye）。
- 周期性维护：地址剔除 rescreen 24h；新地址增量入池 24h。

## 三、关闭时序

- **正常退出**：后端 `main.py` 进程退出 → Electron 守卫检测到退出 → 守卫同步退出（看门狗随后端生命周期）。
- **异常退出**（崩溃/被杀）：守卫 12–25s 检测后自动拉起新后端进程（自愈，无需外部轮询）。

## 四、容灾路径

| 故障 | 表现 | 恢复 |
|---|---|---|
| 后端崩溃 | API 不可达 | Electron 守卫 12–25s 自动拉起 |
| GMGN 限流/封禁 | 熔断器生效 | 熔断期内零请求，45min/6h 后自动恢复 |
| 外部 API 超时 | 该轮数据缺失 | 单点 3s 超时 + 异常捕获，下一轮重试 |
| RPC 429 | 清洗暂停该地址 | RateLimitedError → 调用方退避，下轮重试 |
| DB 锁 | database is locked | WAL + busy_timeout 30s |
| 前端失联 | 页面显示"后端不可达" | 轮询重试，后端恢复即回连 |

## 五、数据新鲜度

- 价格：常驻缓存 price_cache（buys 首屏）；市场页实时快照
- 热度：15min TTL（首轮显示"热度待采集"）
- 信号：后端轮询 60s 粒度；前端 15s 轮询展示
