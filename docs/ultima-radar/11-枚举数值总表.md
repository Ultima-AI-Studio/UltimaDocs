# 11-枚举数值总表 · UltimaRadar

> 状态机/枚举/关键数值的唯一权威源（实现见 db.py 注释、api.py、scoring/scorer.py、signals/fusion.py）。

## 一、状态机

### 地址状态
```
导入 → 清洗(链上验证)
        ├─ 有效 → 监控池（is_filtered=0）
        └─ 无效/刷数据 → is_filtered=1（flags 记录特征）
监控池 → 连续亏损护栏（胜率<30% 且样本≥20）→ fired（归档，前端"已移出"）
```

### 模拟跟单账户
```
active ──负期望熔断──▶ paused（paused_reason）
（reset 可重置回初始资金）
```

### 模拟持仓
```
open ──卖出/止损/止盈──▶ closed（exit_reason, pnl_usd/pct）
```

## 二、枚举表

| 枚举 | 取值 | 含义 |
|---|---|---|
| addresses.source | own / public / kol / madeonsol | 地址来源 |
| addresses.style | 短线猎手 / 波段 / 囤币 | 画像风格 |
| signals.level | info / low / medium / high | 信号级别 |
| watchlist.source | manual / auto | 手动关注 / 热度自动并入 |
| smart_money_trades.action | buy / sell | 买卖方向 |
| smart_money_trades.passive | 0 / 1 | 是否被动地址 |
| signals.exit_flag | 0 / 1 | 离场信号 |
| paper_account.status | active / paused | 模拟账户状态 |
| paper_positions.status | open / closed | 持仓状态 |
| paper_trades.action | buy / sell | 模拟成交方向 |
| heat.sentiment | positive / negative / neutral | 新闻情绪 |

## 三、关键数值

| 数值 | 值 | 出处 |
|---|---|---|
| 评分权重 | 来源 50 + 盈亏 25 + 持仓 15 + 标的 10 | scorer.py（ADR-004） |

## 四、一致性约束

- 任何枚举新增/取值变更须同步本表与 02-数据模型；跨文档引用同值。
- 状态迁移须能追踪（fired 留痕、paper paused_reason、position exit_reason）。
