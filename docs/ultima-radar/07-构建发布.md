# 07-构建发布 · UltimaRadar

## 一、版本号规则

- 语义化 `MAJOR.MINOR.PATCH`：`v0.1.0`（当前，开发中 · 待测试）。
- 未发布正式版前不承诺稳定 API；版本产物归档至 `artifacts/<版本>/`（只读）。

## 二、构建矩阵

| 目标 | 命令 | 产出 |
|---|---|---|
| 后端 | `cd backend && python main.py`（标准库零依赖） | Python 进程 + API 服务 |
| 前端 | `cd frontend && npm install && npm start` | Electron 桌面壳 |
| 一键启动 | `scripts/start_app.bat` / `run_backend.bat` | 后端 + 桌面 |
| 测试 | `python -m pytest tests/` | 3 模块 15 用例 |
| 验证 | `scripts/verify_*.py`（20+ 专项） | 功能级验证脚本 |

## 三、运行环境

| 项 | 要求 |
|---|---|
| OS | Windows（DPAPI 依赖；macOS/Linux 需换密钥存储） |
| Python | 3.12（标准库，无需 pip） |
| Node | 系统 node（gmgn-cli 需 npm 全局安装：`npm install -g gmgn-cli`） |
| 网络 | 出网访问 DexScreener/Helius/GMGN/Google News 等 |

## 四、发布包清单（当前阶段）

| 组件 | 路径 | 说明 |
|---|---|---|
| 后端 | backend/ | 数据管道 + API |
| 前端 | frontend/ | Electron 壳 + index.html |
| 配置 | backend/config.py | 运行参数（见 04） |
| 数据源 key | 软件内配置（DPAPI 加密） | 不随包分发 |

> 正式发布打包（electron-builder 等）未配置，属待办（P2）：当前以源码 + start_app.bat 方式运行。
