## 一、产品定位

Solana memecoin 聪明钱跟监与机会信号桌面应用（M1 walking skeleton）。

一句话：帮用户监控 Solana 链上聪明钱地址动向，融合多源信号产出交易机会信号。

## 四、运行时模型

- 后端：`python main.py` 启动，标准库无第三方依赖
- 桌面端：`npm install && npm start`（Electron）
- 通信：本地 HTTP（127.0.0.1:8721），前后端同机

## 六、双端架构（2026-10-18）

采集组件已从本地剥离到 VPS，本地退化为「网关壳」：

```
┌───────────── 本地（应用壳） ─────────────┐        ┌────────────── VPS（采集服务） ──────────────┐
│ Electron (frontend/)                    │        │ deploy/ultimaradar-server/                  │
│   └ renderer/index.html（前端零改动）    │        │   main.py  采集线程+API+paper+备份/清理       │
│          │ http://127.0.0.1:8721/api/*  │        │   api.py    REST（X-API-Token 鉴权）          │
│          ▼                              │        │   db.py     全量表（data/ultimaradar.db）     │
│ backend/gateway.py（本地网关）           │  ────► │   模块集    地址/链上/采集/信号/paper/回测       │
│   ① 转发 VPS（带 token）                │ 转发    │   .env      数据源 key（无 DPAPI）             │
│   ② GET 成功写本地缓存 local_cache.db   │ ◄────  │   systemd  开机自启 + 崩溃自愈                │
│   ③ VPS 不可达 → 缓存回退（stale 标记）  │        │                                              │
└──────────────────────────────────────────┘        └──────────────────────────────────────────────┘
```

- 本地壳入口：`backend/main.py` → 仅跑 `gateway.py` 网关（127.0.0.1:8721，Electron 守卫逻辑不变）；
- 原始完整后端（采集版）保留在 `deploy/ultimaradar-server/`（服务器部署包，与本地同源）；
- 配置：`backend/data/local_config.json`（vps_url / api_token / configured）；未配置时网关离线（health.ok=false、缓存或 503）；
- 缓存兜底：GET 成功响应存本地 SQLite（24h TTL），VPS 断线返回最近缓存并打 `stale/cached_at`；
- 鉴权：VPS 除 `/api/health` 外要求 `X-API-Token`（值 = 服务器 .env 的 ULTIMARADAR_API_TOKEN，本地壳 local_config.json 同值）。
