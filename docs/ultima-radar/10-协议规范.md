# 10-协议规范 · UltimaRadar

> 网络协议适配与消息契约（10 协议规范标准）。分两层：本地 API 协议（内部）与外部数据源协议（适配层）。

## 一、本地 API 协议（内部）

- 传输：HTTP/1.1 over TCP，仅监听 `127.0.0.1:8721`（不回环外地址）。
- 请求：GET 无参 / POST·DELETE 带 `Content-Type: application/json`。
- 响应：`application/json`；成功 `{"ok":true,...}`；失败 `{"ok":false,"error":"<text>"}`。
- 消息号：无（REST 路径即消息号，见 01-接口契约端点表）。
- 错误分类：见 01 §三（业务失败/服务不可达/异常兜底）。

## 二、外部数据源协议（适配层）

| 源 | 协议 | 认证 | 限流约定 |
|---|---|---|---|
| DexScreener | REST + Pair API | 无 key | 宽松；token 解析需 token-profile 端点 |
| Helius | RPC（JSON-RPC 2.0） | 多 key 池轮换 | 429 退避；全量清洗仅启动后台一次 |
| GMGN | gmgn-cli（官方 CLI 封装） | 免费 key（软件内填） | Free 权重 5/秒×2 裕量 + 全局 3s + 熔断 45min/6h |
| MadeOnSol | REST | API key | 每日配额：leaderboard 2 / feed 96 / coordination 48 / me 4 |
| Birdeye | REST | X-API-KEY | 仅 logo 第三级兜底 + 失败 15min 缓存 |
| Google News | RSS | 无 | 懒采集 15min TTL |
| pump.fun | 链上监听 + REST | 无 | 60s 轮询 |

## 三、消息/数据契约

- 时间戳：API 层 unix 秒（`ts`）；DB 层 SQLite datetime 文本（`created_at`）——见 02-数据模型。
- 金额字段后缀约定：`*_usd` / `*_sol`（见 01 §一）。
- 幂等：smart_money_trades.signature UNIQUE（事件去重）；exec_map 防重复建档。

## 四、一致性约束

- 本表与 01-接口契约（本地）、04-参数基线（配额数值）引用同一口径；改动任一须同步。
- 新数据源接入必须在此登记协议/认证/限流，并进 16 功能范围分层。
