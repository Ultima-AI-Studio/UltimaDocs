# 01-接口契约 · UltimaRadar

> HTTP API 契约（唯一权威源：VPS `deploy/ultimaradar-server/api.py`；本地 `backend/gateway.py` 为转发层）。
> 双端拆分后（2026-10-18）：本地壳监听 `127.0.0.1:8721` 并把 `/api/*` 转发到 VPS 采集服务；
> 前端视角契约不变（同机 127.0.0.1:8721，零改动）。
> 返回统一 JSON；GET 无参；写操作 POST/DELETE 均携带 `Content-Type: application/json` 请求体。
> 错误统一形态：`{"ok": false, "error": "<原因>"}`；成功写操作：`{"ok": true, ...}`。
> **鉴权**：VPS 除 `/api/health` 外均需请求头 `X-API-Token: <ULTIMARADAR_API_TOKEN>`（401 拒绝）；
> 本地壳网关自动携带（读 `backend/data/local_config.json` 的 api_token）。
> **缓存兜底**：本地壳 GET 成功响应写 `backend/data/local_cache.db`（24h TTL）；VPS 不可达时返回最近缓存并附加 `stale: true` / `cached_at`（仍 200，前端可据此提示）。

## 一、命名与编码规范

- 路径：小写 kebab-case（`/api/xxx`）；多词用连字符（`/api/wallet/detail`）。
- 字段：小写 snake_case；时间统一 unix 秒（`ts`）或 `YYYY-MM-DD HH:MM:SS`（`created_at`）。
- 金额：USDT 用 `*_usd` 后缀；SOL 用 `*_sol` 后缀；价格一律 `price_usd`。
- 分页参数：`limit`（默认见各端点）；列表按时间倒序。

## 三、错误码约定

| 形态 | 含义 | 前端处理 |
|---|---|---|
| `{"ok": false, "error": "<text>"}` | 业务失败（参数/源未配置/验证不通过） | toast 展示 error 原文 |
| HTTP 非 200 | 服务未启动/异常 | 前端轮询标"后端不可达" |
| 端点异常兜底 | api.py do_* 顶层 try/except 返回 `{"error": "<exception>"}` | 按后端不可达降级 |

## 四、约束与依赖

- 全局限速：GMGN 相关端点（wallet/detail）受 `gmgn_client` 全局 3s 间隔 + 熔断保护，接口层不绕过。
- logo 补全：signals/buys/outcomes/paper/pumpfun/market 共用 `_enrich_logo`（缓存命中零请求）。
- 热度字段：market 端点热度由后端轮询写入 + 懒采集兜底（15min TTL），首轮可能返回"热度待首轮采集"。
