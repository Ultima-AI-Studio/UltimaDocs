## 二、品牌规范要点

### 2.1 品牌组合参数规范（v1.4，2026-10-29 定版）

**组合 = 纯品牌英文文字（实时渲染，不拼合成图，不放 logo 图片）**

> **2026-10-29 用户拍板：UI 界面所有 logo 展示区一律不放图片（宇航员半身像/头盔标），只显示品牌英文文字**。主 logo 图形资产（`ultima-logo/astronaut.png` / `helmet.png`）仅保留用于应用图标、启动页等非界面品牌区场景（见 §2.1 注）。

**① 英文字体**
- 字体：**HarmonyOS Sans**（`fonts/HarmonyOS_Sans.ttf`）；中文用 HarmonyOS Sans SC
- **加粗：Bold 700**
- **字间距：主标 0.5px；副标 1px**
- 禁止改用 Segoe UI / 微软雅黑等其他字体

**② 文字颜色**

| 场景 | Ultima（主品牌） | 子品牌产品名（Console / Radar / Gold …） |
|---|---|---|
| 深色底（deep） | `#EAF2FF`（近白） | 默认 `#4D9FFF`（accent 蓝）；可按产品主题换色（需登记） |
| 浅色底（light） | `#0B1220`（黑） | 默认 `#1D6FFF`（深蓝）；可按产品主题换色（需登记） |

- **子品牌换色规则**：默认全系统一 accent 蓝；产品可自定义 accent 色（如 UltimaGold → 金色 `#D4AF37`、UltimaRadar → 雷达主题色），**自定义须在品牌库 README 登记**，结构保持"Ultima 主色 + 子品牌 accent"两段式不变。

**③ 尺寸与间距（缩放只定字号，其余按比例换算）**

- 基准：**2560×1600 设计稿下主标字号 = 48px**（预览 HTML 实测，Bold 700）
- 缩放公式（横竖分基准）：
  - 横屏：`主标字号 = 48px × min(目标宽 ÷ 2560, 目标高 ÷ 1600)`
  - 竖屏：`主标字号 = 48px × min(目标宽 ÷ 1600, 目标高 ÷ 2560)`

| 形态 | 布局 | 图形高 | 主标字号 | 文字间距 | 对齐方式 |
|---|---|---|---|---|---|
| **横屏** | 纯文字，左右两段（Ultima 主标 + 子品牌副标） | —（无图形） | **48px**（2560 基准） | **列间距 = 字号 × 0.36**（48px → ≈17px） | 两段文字**垂直居中**；组合整体在容器内**水平居中** |
| **竖屏** | 纯文字，上下两行（Ultima 主标 + 子品牌副标） | —（无图形） | **48px**（1600×2560 基准） | **行间距 = 字号 × 0.47**（48px → ≈23px） | 文字与副标**水平居中**（以主标垂直中心线为轴，多行文字每行独立水平居中）；组合整体在容器内**水平居中** |

> 注：组合参考图（`combo/`）为独立横幅物料参数（88px@1200 宽），仅作视觉示例，APP 界面一律按上表 48px 基准与缩放公式执行。
> **logo 图片应用边界**：`astronaut.png` / `helmet.png` 仅用于 **应用图标（Launcher / App Icon）、启动页品牌图** 等非界面品牌区场景；**界面内品牌区（导航/页头/登录/角标/悬浮球/产品页 logo 位）一律只放品牌英文文字，不渲染 logo 图片**。

### 2.1.1 组合居中样式标准（水平居中 / 垂直居中）

| 样式 | 规则 | 适用场景 |
|---|---|---|
| **水平居中（组合整体）** | 两段文字作为一组，在容器水平方向居中（左右留白相等，上下按 ③ 间距） | 启动页、Banner、封面、物料中央排布 |
| **水平居中（竖屏内部）** | 文字块以主标垂直中心线为轴水平居中；多行文字（主标/副标）**每行独立水平居中**，行间距按 ③ | 竖屏纯文字（Ultima 上 + 产品下） |
| **垂直居中（横屏内部）** | 两段文字以主标水平中心线为轴垂直居中 | 横屏纯文字（Ultima 左 + 产品右） |
| **左对齐例外** | 界面左上角品牌区为**左对齐**（非居中） | APP 界面品牌区 |

> 居中基准：组合整体居中时，以**组合的几何中心**（两段文字围合矩形的中心）对齐容器中心，而不是仅以其中一段对齐。

**⑤ 产品适配**：其他产品改产品名文字即可（子品牌色按 ③ 规则），参数结构不变。

### 2.2 使用标准（何时用横 / 竖 / 深 / 浅）

| 场景 | 形态 |
|---|---|
| **APP 界面品牌区（左上角/导航/页头/登录/产品页 logo 位，全部界面场景）** | **纯英文文字**（Ultima + 产品名，按 deep/light 着色），**不放 logo 图片**（2026-10-29 用户拍板） |
| 无 logo 浮窗场景（启动页、Banner、外部物料、横屏 2560×1600 宽屏品牌区） | **横屏纯文字**（Ultima 主标 + 产品副标，无图形） |
| 窄屏/竖屏界面品牌区（竖屏 1600×2560 顶部、启动页竖版） | **竖屏纯文字**（Ultima 上 + 产品下，无图形） |
| 深色主题界面 / 深色封面 / 深色启动帧 | **deep（白字）** |
| 浅色主题界面 / 浅色封面 / 白底文档 | **light（黑字）** |
| **应用图标 / 启动页品牌图 / 系统资产** | 宇航员半身像 / 头盔（`astronaut.png` / `helmet.png`）——仅此非界面场景保留图形 |

### 2.3 其他要点

- 悬浮球浮窗：**纯英文文字**（Ultima 或产品名，v1.4 起不再用头盔图形）+ 镜片推光同框锁死 108vp，无圆底、无呼吸灯（v1.1-N3 定稿）
- 启动页：自定义首帧 + 星星闪烁全程 + 镜片推光 1.5s + 整体渐隐 0.5s，总 2s 进主界面（v1.1-N4 定稿）

## 三、维护规则

1. 各产品引用品牌资产时优先指向本库路径，不复制进产品目录（产品内打包资源除外）。
2. 品牌资产变更：更新本清单 → 同步镜像 `ultima-docs-repo/docs/brand/` → push GitHub。
3. 禁止删除/改名在库资产而不更新本 README。
