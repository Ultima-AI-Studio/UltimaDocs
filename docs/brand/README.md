## 二、品牌规范要点

### 2.1 品牌组合参数规范（v1.2，2026-10-19 定版）

**组合 = 透明底头盔 logo + 字体文字（实时渲染，不拼合成图）**

**① logo**
- 文件：`ultima-logo/helmet.png`（透明底），按场景定尺寸（见下表），可加光晕/投影

**② 文字字体**
- 主标字体：`Segoe UI`（优先）/ `Microsoft YaHei`，**Bold 700**，字距 1px
- 主标内容：`Ultima` + 产品名（如 `Console` / `Radar`），两段可分别着色

**③ 文字颜色**

| 场景 | Ultima | 产品名 | 备注 |
|---|---|---|---|
| 深色底（deep） | `#EAF2FF`（近白） | `#4D9FFF`（accent 蓝） | 深蓝渐变底 #101A30→#0A0F1E→#070B14 |
| 浅色底（light） | `#0B1220`（黑） | `#1D6FFF`（深蓝） | 浅蓝白渐变底 #FFFFFF→#F1F5FB→#E4EBF5 |

**④ 字号与布局**

| 形态 | 布局 | logo 尺寸 | 主标字号 | logo↔文字间距 |
|---|---|---|---|---|
| 横屏（宽屏品牌区/导航/Banner） | logo 左 + 文字右，垂直居中 | 高 200（1200 宽基准） | **88px** | 32 |
| 竖屏（启动页/竖屏顶部） | logo 上 + 文字下，水平居中 | 高 280（640 宽基准） | **68px**（不超卡片边界） | 32 |

- 缩放规则：上述为基准值，实际场景按同比例缩放（如横屏 2560 宽 ≈ 基准 ×2.13，字号 ≈ 88px×2.13）
- 光晕：深色底 `drop-shadow(0 0 34~40px rgba(70,150,255,.55))`；浅色底 `drop-shadow(0 4px 18px rgba(30,80,200,.22))`

**⑤ 产品适配**：其他产品改产品名文字即可，参数结构不变。

### 2.2 使用标准（何时用横 / 竖 / 深 / 浅）

| 场景 | 形态 |
|---|---|
| 宽屏界面品牌区（导航头部、横幅 Banner、横屏 2560×1600） | **横屏**（logo 左 + 文字右） |
| 窄屏/竖屏界面品牌区（启动页、竖屏 1600×2560 顶部） | **竖屏**（logo 上 + 文字下） |
| 深色主题界面 / 深色封面 / 深色启动帧 | **deep（白字）** |
| 浅色主题界面 / 浅色封面 / 白底文档 | **light（黑字）** |
| 悬浮球、角标、小尺寸控件 | 直接用透明底 helmet（不带文字） |

### 2.3 其他要点

- 悬浮球浮窗：头盔 logo + 镜片推光同框锁死 108vp，无圆底、无呼吸灯（v1.1-N3 定稿）
- 启动页：自定义首帧 + 星星闪烁全程 + 镜片推光 1.5s + 整体渐隐 0.5s，总 2s 进主界面（v1.1-N4 定稿）

## 三、维护规则

1. 各产品引用品牌资产时优先指向本库路径，不复制进产品目录（产品内打包资源除外）。
2. 品牌资产变更：更新本清单 → 同步镜像 `ultima-docs-repo/docs/brand/` → push GitHub。
3. 禁止删除/改名在库资产而不更新本 README。
