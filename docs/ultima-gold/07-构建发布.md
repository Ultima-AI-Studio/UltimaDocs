# 07 构建与发布（UGP-44 更新）

## 1. 可复现构建（clean_build_reproducible_inputs）

- 从干净受控环境构建，不复用未验证 dist；锁定输入 = 源码提交哈希 + 依赖锁 + schema 版本。
- 相同锁定输入重新构建 → 产物 SHA256 一致（可复现）；任何差异必须有解释（输入变化/产物集合变化不得静默通过）。
- 完整类型门必须退出 0。

## 2. 安装 / 升级 / 回滚（install_upgrade_rollback）

- 升级后新增的业务数据写入数据目录（%APPDATA% 类位置），程序文件与数据分离；
- 回滚只替换程序文件，数据目录保留 → 切换后新增业务数据不因回滚丢失。

## 3. 产物清单（artifact_manifest_complete）

- 每个发布产物：真实路径、大小、SHA256、适用平台；
- 清单文本不得包含 password/secret/api_key/private_key/credential 等秘密标记。

## 4. 边界

- SDK 原代币测试、PayWindow 测试、真实收款测试分别报告，不合并冒充；
- 版本号在候选证据通过后统一绑定；签名/证书/域名等外部操作保留授权边界；
- 不为凑旧体积指标填充无用文件。
