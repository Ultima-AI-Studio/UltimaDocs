# 08-流程清单.md（开发流程 / 变更管理 / 权威文档清单）

> 本文件是流程与文档的**唯一登记处**。新增/改名文档必须在此登记，否则视为越界。

## 1. 开发流程（工单化循环）

```
1. 环境门：09-工程骨架.md 就绪检查 8 项全绿 → 未就绪不进开发
2. 逐 T 开发：工单"写什么" → 实现 → 验收 Gate → AI 自证（贴命令/日志/diff 证据，禁止"预计通过"）
3. 工单 DoD：全部 T 过 + 总验收 + 文档同步 + 冻结标记
4. 阶段报告 → AI 复核 → 冻结 tag（stageN-frozen）→ 归档 docs/reports/
5. 未决项（OPEN-xx）移交 15-基线台账.md；新需求走第 2 节变更流程
```

## 2. 变更管理（防无限拓展，五层封闭）

1. **任务级封闭**：工单"写什么 / 验收 / 禁止"三段式；清单外代码 = 越界打回
2. **工单级封闭**：范围冻结（只做/不做）+ 任务表固定
3. **阶段级封闭**：DoD + 冻结门（未冻结不进下阶段）
4. **项目级封闭**：16-功能范围.md = 唯一事实源，新增需求必须走变更
5. **验收封闭原则**：验收清单即边界，**验收时不得追加新需求**；清单外发现 = 登记 15 台账 → 新工单 → 后续阶段实施，不就地膨胀

**变更流程**：
```
新需求/清单外发现 → 记 15-基线台账（OPEN-xx）→ AI 裁定归属与优先级
  → A 级变更（架构/范围/合规）：AI 评估 + 用户必须拍板
  → 非 A 级：登记规划 → 后续阶段新工单实施
```

## 3. 审批矩阵

| 事项 | 自动化 | 用户 |
|---|---|---|
| 任务级/工单级验收 | AI 自证 + 复核 + 冻结 | — |
| 阶段报告 + 冻结 | AI 复核落 tag | 例外介入（不回复 = 通过，异议才打回） |
| 新需求登记 | AI 裁定归属/优先级 | — |
| A 级变更（架构/范围级） | AI 评估 | **必须拍板** |
| 业务决策（邀请机制/定价/合规/数据源） | AI 给建议 | **必须拍板（开工前一次清）** |
| 生产发布 | AI 准备 | **唯一人工确认点** |

> 与 v2.35 投喂指令 v2 的 2 项人工例外一致：① 生产凭据一次性索取；② 生产发布唯一确认。

| 安全扫描 | SAST 每次提交必跑（高危=阻塞）；依赖版本锁定 + CVE；发布前 SBOM | 扫描报告留档 |

## 6. 报告口径（铁律）

- 时间分列（不合并时间段）
- 未见项写"范围内未见"（不写"无"）
- 验收按真实口径（不估算/不推断）
- 旧责任列"待处理"
- 决策仅列未裁决项
