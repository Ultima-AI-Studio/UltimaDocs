## 1. 目录树（目标 monorepo）

```
xauusd/
├── docs/                    本文档库（唯一权威源）
├── fixtures/recorded_ticks/ 录制行情夹具（G2 复现前提）
├── backend/                 核心服务（推送/TTS/链上/订单/财务/防刷限流；信号判定经消息队列接入）
├── pc-client/               【22 方案】Windows 端安装版应用（行情分析工作台 + MT 绑定采集；Python+PySide6）
├── ml-engine/               【CHG-001】引擎模块（规则基线 + ML 推理组件接口 + 训练脚本预研，3060 机部署）
├── web-admin/               Web 后台 18 模块
├── web-user/                用户端 6 页
├── app-android/             Android 客户端
├── app-ios/                 iOS 客户端（构建走 CI macOS runner）
├── scripts/
│   ├── precheck            本地预检（构建+单测+扫描，一条命令）
│   └── reconcile           财务对账脚本（diff=0 判定）
├── migrations/              数据库迁移（幂等可重跑，退出码 0）
├── tests/                   单测/压测/门禁验收脚本
└── secrets/                 本地 secrets（不入库、不提交）
```

## 2. 依赖白名单（唯一合法外部依赖）

| 依赖 | 用途 | 版本策略 |
|---|---|---|
| CosyVoice（本地轻量模型） | TTS | 版本锁定 |
| 推送通道 SDK（FCM / APNs 沙盒 / 厂商测试） | 推送 | 版本锁定 |
| 链查询 SDK（TRON / EVM） | 链上确认 | 版本锁定 |
| 可视化/图表库（Web） | 后台统计 | 版本锁定 |
| 测试框架（适用者） | 单测/验收 | 版本锁定 |
| ML 框架（PyTorch GPU，CHG-001） | ML 模型训练与推理（3060 引擎机） | 版本锁定 + CVE |

- 白名单外依赖一律禁止；确需新增 → 记 15 台账 + 08 变更（A 级拍板）。
- 自建沙盒资产（Mock 钱包 / Mock APNs / 通道模拟器 / 行情夹具）= 自建产物，不计外部依赖。
- CVE 扫描 + License 审查（不采 GPL 底座）纳入 precheck。

## 5. 技术栈（已冻结，2026-10-07 用户拍板）

| 层 | 选型 | 说明 |
|---|---|---|
| 后端 | Python + FastAPI | 主服务 API / 推送 / 订单 / 后台；与 ML 生态同语言 |
| 数据库 | PostgreSQL | 订单/财务对账（diff=0）与并发写入 |
| 移动端 | 原生 Kotlin | 安卓 MVP（FCM 集成最直接）；iOS 技术栈 v1.1 单独评估 |
| CI | GitHub Actions | 含 macOS runner（iOS 构建预留） |
| ML 引擎机 | Python + PyTorch（GPU） | CHG-001；3060 推理/训练 |

> 技术栈变更 = A 级变更（08 流程）；ADRs 见 14-ADR ADR-013。
