# 06 安全规范（UGP-43 更新）

> 本文件补充发布安全与外部依据口径；不构成法律或资金安全认证（任务卡完成标准口径）。

## 1. 发布安全门（release_security_gates）

- 高危/关键缺陷（unverified-payment、log-secret-leak、越权、恶意回调、日志泄漏等）必须**修复并重验全绿**后才可进入发布判断；扫描范围 = 实际发布包（dist/site、dist/server 等），未覆盖的路径不计入通过。
- 严重级别仅 critical/high/medium/low；非法级别拒绝登记。

## 2. 凭据轮换（old_credentials_invalid）

- 被要求轮换的旧值必须**确实无法认证**（轮换前提），否则轮换不生效；
- 轮换报告只记录新值哈希前缀与旧值失效状态，**不记录原值**（旧值/新值明文不出现在任何报告/日志/源码）。

## 3. 许可与数据授权（licenses_scoped）

- 每个被发布或再分发资产（图表库、字体、图标、SDK 底座、模型音色、行情/新闻再分发）必须有许可依据（来源记录）；
- 缺失许可依据 → 不得写通过（该资产不得进入发布判断）。

## 4. 边界

- 「能抓取」「有免责声明」「不持私钥」不视为授权/合规/资金安全证明；
- 材料缺失只阻断相关对外功能；不自行采购或签约。
